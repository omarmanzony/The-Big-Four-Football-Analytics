<h1 align="center">The Big Four: Football Analytics</h1>

<p align="center">
An interactive Microsoft Power BI dashboard designed to analyze goal-scoring performance, player statistics, tournament performance, and scoring patterns across four world-class football players.
</p>

<h2>Project Overview</h2>

The Big Four: Football Analytics is an interactive sports analytics dashboard developed using Microsoft Power BI to explore and compare the scoring performance of Lionel Messi, Cristiano Ronaldo, Robert Lewandowski, and Neymar.

The dashboard provides an analytical view of goals, matches with scoring, goals per match, tournaments, goal types, assists, opponents, match periods, and player positions through interactive visualizations and filters.

<h2>Business Objectives</h2>

- Compare goal-scoring performance across the four selected players.
- Analyze goals scored across different years and tournaments.
- Understand the distribution of goals by type, including penalties, headers, and free kicks.
- Compare home and away goal-scoring performance.
- Analyze non-penalty goals across the selected players.
- Explore assist providers and opponent scoring patterns.
- Examine scoring performance across different match periods.
- Analyze goals by player position.
- Provide an interactive dashboard for exploring football performance data.

<h2>Key Performance Indicators</h2>

The dashboard includes key football performance metrics such as:

- Total Goals
- Matches with Scoring
- Goals per Match
- Total Tournaments
- Penalty Goals
- Non-Penalty Goals
- Total Opponents
- Total Assists

These metrics provide an overview of scoring performance and help compare different aspects of each player's contribution.

- Top Opponents Scored Against
- Goals by Match Period
- Goals by Player Position
